# 有邻 DAO 文档索引

- `部署记录.md`：Monad Testnet 四份合约地址、交易哈希、验证链接和链上配置；
- `演示账户说明.md`：公开测试地址及其角色，不含私钥；
- `黑客松演示路径.md`：从连接钱包、创世捐款到完整项目生命周期的演示步骤；
- `monad-testnet.json`：机器可读的部署配置和交易证明；
- `demo-projects.json`：四个原协议真实项目记录；
- `genesis-demo.json`：创世金库真实捐款与治理闭环。

公开仓库和 Sites 源仓库相互独立。开发根目录不执行 `git init`，现有 `youlin-interface/.git` 的 Sites `origin` 不得修改。所有 `.env`、私钥、助记词、服务凭据和本地演示密钥均被排除。
