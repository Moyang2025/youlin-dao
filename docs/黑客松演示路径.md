# 黑客松演示路径

## 1. 连接与恢复

打开生产站点，使用安装了 MetaMask 等注入钱包的浏览器连接。网站没有中心化注册：钱包地址就是链上身份。切换到 Monad Testnet 后，首页会从链上读取 P、R、项目索引和创世捐款记录。

若出现“未检测到浏览器钱包”，先安装/启用钱包扩展并刷新；手机可在钱包 App 的内置浏览器打开网站。

## 2. 新用户获得 R

进入“创世项目与捐款者共治金库”：

1. 输入不超过个人剩余 100 MON 额度的金额；
2. 钱包确认 `donate()`；
3. 同一笔交易把 MON 留在金库、铸造等额 R，首次捐款再铸造创世 P；
4. 刷新后余额、金库和捐款者数量全部从链上恢复。

创世项目没有全局募捐上限。

## 3. 金库治理

捐款者可创建固定收款地址、固定金额和用途承诺的提案。提案使用创建时的累计捐款快照，权重为 `ln(1 + 捐款 MON)`。至少三名快照捐款者实际投票，赞成权重达到已投赞成与反对总权重的 66% 才通过；不投票不算反对。通过后任何人都可执行，管理员不能绕过投票提款。

页面已经显示真实的已执行提案 #1，可直接核对三票、100% 赞成和 0.005 MON 支出。

## 4. 原协议流程

项目广场保留四个真实项目：

- 草案待共同发起；
- 第一轮募捐；
- 第一轮失败并退款；
- 两轮募捐、中期 80、结项 90、无挑战结算的完整项目。

演示者还可以：

1. 用 R 创建项目草案并邀请共同发起人；
2. 各发起人分别确认并锁定自己的 R；
3. 第一轮捐款达到目标 50% 后提交中期材料；
4. 捐款者按对数权重评分，60 分开放第二轮；
5. 第二轮资金在同一交易直接进入项目钱包；
6. 提交结项材料、评分、挑战/争议投票并最终结算。

## 5. 证明

合约地址、部署哈希、Sourcify 验证和真实交易链接见 `docs/部署记录.md`。测试结果为 53/53，通过整体 92.28% 行覆盖；浏览器桌面端、390×844 手机端和无钱包错误状态均已验收。
