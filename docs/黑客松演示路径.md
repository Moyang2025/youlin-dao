# 黑客松演示路径

页面必须持续显示：

> Monad Testnet Demo：为黑客松演示缩短了时间窗口；测试 MON 不构成真实募捐。

建议 6–8 分钟演示：

1. 打开“我的有邻”，连接 Monad Testnet 钱包，展示总 R、可用 R、锁定 R
   和不可转让 P 均来自链上读取。
2. 进入项目广场，打开已结算项目 D，沿发起、首轮、中期、二轮、结项和
   无挑战结算查看完整状态与 Monadscan 交易。
3. 打开项目 C，说明首轮未达标后任何人都能判定失败，发起质押已解锁，
   捐款由原账户主动退款，但 P 永久保留。
4. 使用评委测试钱包向项目 B 捐赠少量 MON：钱包签名 → pending →
   Monadscan 确认 → 卡片刷新 → 首次捐款获得 P。
5. 展示中期/结项评分资格由 P、捐款、非发起人和窗口共同决定；权重是
   `ln(1 + donationMON)`，60 分才开放第二轮。
6. 展示挑战与争议：挑战质押 R，三名争议投票者按 `sqrt(stakeR)` 加权，
   60% 支持才成功。
7. 回到账户页，说明 R 变化、P、捐款与项目结果可从链上恢复，刷新页面
   不会丢失。

演示前检查：

- 三合约 Monadscan 页面显示源码已验证；
- bootstrap 已关闭；
- `deployments/demo-projects.json` 中的项目 ID 能被前端读取；
- 至少一个评委操作账户有测试 MON；
- 桌面与手机网络正常，备用 RPC 可用；
- 不展示 `.env`、私钥、助记词或 API 密钥。
