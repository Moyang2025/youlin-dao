# 黑客松演示路径

## 1. 连接与恢复

打开生产站点，使用安装了 MetaMask 等注入钱包的浏览器连接。网站没有中心化注册：钱包地址就是链上身份。切换到 Monad Testnet 后，首页会从链上读取 P、R、项目索引和创世捐款记录。

若出现“未检测到浏览器钱包”，先安装/启用钱包扩展并刷新；手机可在钱包 App 的内置浏览器打开网站。

连接后，在“我的有邻”点击“创建链上资料”或“编辑链上资料”，设置昵称、头像 URI 与自我描述并由钱包确认。合约只允许当前地址修改自己，昵称可以重复；资料公开保存在 Monad Testnet，刷新或换设备后仍可恢复。头像支持 `https://`、`http://` 与 `ipfs://`，不要填写隐私信息。

## 2. 新用户获得 R

进入“创世项目与捐款者共治金库”：

1. 输入不超过个人剩余 100 MON 额度的金额；
2. 钱包确认 `donate()`；
3. 同一笔交易把 MON 留在金库、铸造等额 R，首次捐款再铸造创世 P；
4. 刷新后余额、金库和捐款者数量全部从链上恢复。

创世项目没有全局募捐上限。

## 3. 金库治理

捐款者可创建固定收款地址、固定金额和用途承诺的提案。提案使用创建时的累计捐款快照，权重为 `ln(1 + 捐款 MON)`。至少三名快照捐款者实际投票，赞成权重达到已投赞成与反对总权重的 66% 才通过；不投票不算反对。通过后任何人都可执行，管理员不能绕过投票提款。

页面已经显示真实的已执行提案 #1，可直接核对三票、100% 赞成和 0.005 MON 支出。

## 4. 原协议流程

项目广场保留四个真实项目：

- 草案待共同发起；
- 第一轮募捐；
- 第一轮失败并退款；
- 两轮募捐、中期 80、结项 90、无挑战结算的完整项目。

演示者还可以：

1. 创建项目草案并直接公开到项目广场，无需预填共同发起钱包；
2. 任何拥有可用 R 的账户都可自主质押，人数和总质押同时达标后激活；
3. 第一轮捐款达到目标 50% 后提交中期材料；
4. 捐款者按对数权重评分，60 分开放第二轮；
5. 第二轮资金在同一交易直接进入项目钱包；
6. 提交结项材料、评分、挑战/争议投票并最终结算。

## 5. 证明

合约地址、部署哈希、Sourcify 验证和真实交易链接见 `docs/部署记录.md`。测试结果为 59/59，通过整体 92.56% 行覆盖；浏览器桌面端、390×844 手机端和无钱包错误状态均已验收。

## 6. 问答环节实时捐款

项目广场第一张卡片为 Project #7“偏远地区青少年编程启蒙工作”，状态为第一轮募捐，第一轮上限 15 MON，截止北京时间 2026 年 8 月 10 日 22:00。三个演示账户已经分别捐赠 1 MON，当前进度为 3/15 MON。

1. 连接自己的 Monad Testnet 钱包；
2. 在 Project #7 卡片点击“捐款”；
3. 输入不超过第一轮剩余额度的测试 MON；
4. 在钱包确认真实交易；
5. 等待确认后展示捐款进度、项目 P 与新增 R，并刷新页面证明状态可从链上恢复。

Project #6 是 Demo 视频录制时的一小时窗口版本，现已标记为首轮未达标；问答环节务必选择截止时间显示为 `08/10 22:00` 的 Project #7。
