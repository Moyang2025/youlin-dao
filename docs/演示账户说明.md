完整公开角色表位于 `youlin-contracts/deployments/demo-wallets.public.json`：

- 3 个共同发起账户；
- 4 个捐款账户；
- 2 个挑战账户；
- 3 个争议陪审账户。

部署账户 `0x00A206fcCD057360F173D31A2f6090C74f9F456c` 只负责测试网部署、权限配置、暂停和参数维护。它不是金库资金所有者：创世金库没有管理员提款函数，任何支出必须经捐赠者投票。

普通演示建议使用自己的 MetaMask 测试账户：

1. 切换到 Monad Testnet（chain ID `10143`）；
2. 准备测试 MON；
3. 连接原站；
4. 向创世项目捐款获得 R/P；
5. 用 R 参与共同发起，或对创世金库提案投票。
