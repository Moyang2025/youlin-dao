# 演示账户说明

演示脚本至少需要 12 个不持有真实资产的 Monad Testnet 钱包：

| 索引 | 角色 |
| --- | --- |
| 1–3 | 三位共同发起人 |
| 4–7 | 四位捐款/评分账户 |
| 8–9 | 两位挑战账户 |
| 10–12 | 三位争议投票账户 |

同一钱包可以在不同项目承担不同角色，但在同一项目中，发起人不能评分或
挑战，挑战者不能成为争议投票者。脚本会把公开地址写入
`deployments/demo-projects.json`，不会写入私钥。

私钥保管规则：

- 仅放在本机 `youlin-contracts/.env` 的 `DEMO_PRIVATE_KEYS`；
- `.env` 已被 Git 忽略；
- 不通过聊天、截图、终端回显或前端环境变量传递；
- 只使用测试网资产；
- 评委体验优先使用自己的测试钱包，不分发团队私钥。

执行顺序：

```powershell
npm run bootstrap:demo
npm run seed:demo
```

bootstrap 会为演示地址初始化 100 R，并在同一流程末尾永久关闭。
